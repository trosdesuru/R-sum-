## 🛠️ Tecnologías Utilizadas

Este proyecto está construido con las siguientes tecnologías:

- **Frontend:** React 19, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Base de Datos:** Próximamemte MongoDB
- **Despliegue:** Vercel
- **Otros:** API de terceros
